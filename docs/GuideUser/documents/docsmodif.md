# Comment modifier un modèle de document ?
Votre administrateur a dû vous indiqué l'espace disque ou sont situés les Modèles de documents.

Vous pouvez les modifier comme des documents Word habituels.

Vous pouvez inserer des **tokens** reprenant des informations de la base de donnée.<br>
Pour lister les tokens disponibles **CiviOffice > Available Tokens**.
