# In memoriam

Les donneurs expriment leur souhait ou non d'affichage de leur nom sur la steèle ou un site web. 

Pour lister les donneurs ayant émis ce souhait et décédés sur une période donnée,<br>
allez à **Cérémonies > In memoriam**

Vous pouvez sélectioner une période pour la date de décès.

POur exporter : **Actions > Download Spreadsheet > Format xlsx**.
